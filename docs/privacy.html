1. Introduction 1. Introdução

This Privacy Policy describes how Gerador de Macaco Aleatório collects, uses, and stores data from Discord users and servers. By adding or using the bot, you agree to the practices described in this document.

Esta Política de Privacidade descreve como o Gerador de Macaco Aleatório coleta, utiliza e armazena dados de usuários e servidores do Discord. Ao adicionar ou utilizar o bot, você concorda com as práticas descritas neste documento.

2. Data Stored 2. Dados armazenados

The bot permanently stores only the data strictly necessary for its operation. Message content is never part of this data — see section 3 for how message content is processed.

O bot armazena permanentemente apenas os dados estritamente necessários para seu funcionamento. O conteúdo das mensagens nunca faz parte desses dados — veja a seção 3 para saber como o conteúdo das mensagens é processado.

  • Discord user ID and username — for rankings and match history.
  • Server (guild) ID and name — to separate data between different servers.
  • Game statistics — wins/losses in rock-paper-scissors and personal records for entertainment commands (howgay, pp, simp, stank).
  • Server language preference — Portuguese or English.
  • Server command prefix — the prefix configured for the server, if changed from the default.
  • ID e nome de usuário do Discord — para rankings e histórico de partidas.
  • ID e nome do servidor (guild) — para separar dados entre servidores distintos.
  • Estatísticas de jogo — vitórias/derrotas no jokenpo e recordes pessoais dos comandos de entretenimento (howgay, pp, simp, stank).
  • Preferência de idioma do servidor — português ou inglês.
  • Prefixo de comando do servidor — o prefixo configurado para o servidor, caso alterado do padrão.

3. Message Content Processing 3. Processamento do conteúdo das mensagens

The bot reads message content in real time for the two purposes described below. In neither case is message content written to a database or retained beyond the moment it is processed.

O bot lê o conteúdo das mensagens em tempo real para as duas finalidades descritas abaixo. Em nenhum dos casos o conteúdo é gravado em banco de dados ou retido além do momento em que é processado.

  • Automated spam detection — the bot compares each message against the author's own recent messages to identify identical content posted across multiple channels within a short time window (10 seconds, threshold of 3 distinct channels), a pattern typical of compromised accounts and spam bots. When this pattern is detected, the bot deletes the duplicate messages and applies an automatic 30-minute timeout to the author.
  • Command interpretation — the bot checks whether a message begins with the server's configured prefix in order to identify and execute a command.
  • Detecção automatizada de spam — o bot compara cada mensagem com as mensagens recentes do próprio autor para identificar conteúdo idêntico publicado em múltiplos canais dentro de uma janela curta de tempo (10 segundos, limite de 3 canais distintos), padrão típico de contas comprometidas e bots de spam. Ao detectar esse padrão, o bot apaga as mensagens duplicadas e aplica um timeout automático de 30 minutos ao autor.
  • Interpretação de comandos — o bot verifica se a mensagem começa com o prefixo configurado no servidor para identificar e executar um comando.

Message content used for spam detection is held only in memory. It is only eligible for comparison within the 10-second window; entries outside that window are purged by a periodic cleanup that runs every five minutes, or when the same user sends their next message. A user's history is cleared immediately when a spam event is handled. Message content used for command interpretation is read only to identify the command and is not retained afterwards.

O conteúdo utilizado na detecção de spam é mantido somente em memória. Ele só é elegível para comparação dentro da janela de 10 segundos; entradas fora dessa janela são removidas por uma limpeza periódica executada a cada cinco minutos, ou quando o mesmo usuário envia sua mensagem seguinte. O histórico de um usuário é apagado imediatamente quando um evento de spam é tratado. O conteúdo utilizado na interpretação de comandos é lido apenas para identificar o comando e não é retido depois disso.

4. Use of Stored Data 4. Uso dos dados armazenados

The data listed in section 2 is used solely for:

Os dados listados na seção 2 são utilizados somente para:

  • Displaying rankings and match history within the server.
  • Persisting personal records between sessions.
  • Applying the language and prefix preferences configured by the server.
  • Exibir rankings e histórico de partidas dentro do servidor.
  • Persistir recordes pessoais entre sessões.
  • Aplicar as preferências de idioma e prefixo configuradas pelo servidor.

Data is not sold, shared, or used for commercial or advertising purposes.

Os dados não são vendidos, compartilhados nem utilizados para fins comerciais ou publicitários.

5. Retention and Deletion 5. Retenção e exclusão

Data is kept while the bot is present in the server or while the user continues to interact with it. To request deletion of your data, contact us through the channels below.

Os dados são mantidos enquanto o bot estiver presente no servidor ou enquanto o usuário continuar interagindo com ele. Para solicitar a exclusão dos seus dados, entre em contato pelos canais abaixo.

6. Security 6. Segurança

Data is stored locally in an SQLite database on the bot host server. No sensitive information (tokens, passwords, emails) is collected.

Os dados são armazenados localmente em banco de dados SQLite no servidor de hospedagem do bot. Nenhuma informação sensível (tokens, senhas, e-mails) é coletada.
