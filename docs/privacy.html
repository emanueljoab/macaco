1. Introduction 1. Introdução

This Privacy Policy describes how Macaco collects, uses, and stores data from Discord users and servers. By adding or using the bot, you agree to the practices described in this document.

Esta Política de Privacidade descreve como o Macaco coleta, utiliza e armazena dados de usuários e servidores do Discord. Ao adicionar ou utilizar o bot, você concorda com as práticas descritas neste documento.

2. Data Stored 2. Dados armazenados

The bot stores in its database only the data necessary for its operation. Message content is not stored in the database.

O bot armazena em seu banco de dados apenas os dados necessários para seu funcionamento. O conteúdo das mensagens não é armazenado no banco de dados.

  • Discord user ID and username — for rankings and match history.
  • Server (guild) ID and name — to associate settings and bot data with Discord servers.
  • Game statistics — rock-paper-scissors rankings and match history, and personal records for entertainment commands (howgay, pp, simp, stank).
  • Server language preference — Portuguese or English.
  • Server command prefix — the prefix configured for the server, if changed from the default.
  • ID e nome de usuário do Discord — para rankings e histórico de partidas.
  • ID e nome do servidor (guild) — para associar configurações e dados do bot aos servidores do Discord.
  • Estatísticas de jogo — rankings e histórico de partidas de jokenpo e recordes pessoais dos comandos de entretenimento (howgay, pp, simp, stank).
  • Preferência de idioma do servidor — português ou inglês.
  • Prefixo de comando do servidor — o prefixo configurado para o servidor, caso alterado do padrão.

Some operational logs may contain command content and are retained for up to 30 days, as described in sections 3 and 5.

Alguns logs operacionais podem conter conteúdo de comandos e são mantidos por até 30 dias, conforme descrito nas seções 3 e 5.

3. Message Content Processing 3. Processamento do conteúdo das mensagens

The bot reads message content in real time for the purposes described below. Message content is not written to the bot's database, but some command information may be retained temporarily in operational logs.

O bot lê o conteúdo das mensagens em tempo real para as finalidades descritas abaixo. O conteúdo não é gravado no banco de dados do bot, mas algumas informações de comandos podem ser mantidas temporariamente em logs operacionais.

  • Automated spam detection — the bot compares each message against the author's own recent messages to identify identical content posted across multiple channels within a short time window (10 seconds, threshold of 3 distinct channels), a pattern typical of compromised accounts and spam bots. When this pattern is detected, the bot deletes the duplicate messages and applies an automatic 30-minute timeout to the author.
  • Command interpretation — the bot checks whether a message begins with the server's configured prefix in order to identify and execute a command.
  • Operational logs — for operation, diagnostics, and security, logs may contain the username, server name, command executed, command result, errors, and content or parameters submitted to commands.
  • Detecção automatizada de spam — o bot compara cada mensagem com as mensagens recentes do próprio autor para identificar conteúdo idêntico publicado em múltiplos canais dentro de uma janela curta de tempo (10 segundos, limite de 3 canais distintos), padrão típico de contas comprometidas e bots de spam. Ao detectar esse padrão, o bot apaga as mensagens duplicadas e aplica um timeout automático de 30 minutos ao autor.
  • Interpretação de comandos — o bot verifica se a mensagem começa com o prefixo configurado no servidor para identificar e executar um comando.
  • Logs operacionais — para operação, diagnóstico e segurança, os logs podem conter o nome de usuário, nome do servidor, comando executado, resultado do comando, erros e conteúdo ou parâmetros enviados aos comandos.

Message content used for spam detection is held only in memory. It is only eligible for comparison within the 10-second window; entries outside that window are purged by a periodic cleanup that runs every five minutes, or when the same user sends their next message. A user's history is cleared immediately when a spam event is handled. Message content that is not included in the operational logs described above is not retained after processing.

O conteúdo utilizado na detecção de spam é mantido somente em memória. Ele só é elegível para comparação dentro da janela de 10 segundos; entradas fora dessa janela são removidas por uma limpeza periódica executada a cada cinco minutos, ou quando o mesmo usuário envia sua mensagem seguinte. O histórico de um usuário é apagado imediatamente quando um evento de spam é tratado. O conteúdo que não fizer parte dos logs operacionais descritos acima não é retido após o processamento.

4. Use of Stored Data 4. Uso dos dados armazenados

The data described in sections 2 and 3 is used solely for:

Os dados descritos nas seções 2 e 3 são utilizados somente para:

  • Displaying rankings and match history.
  • Persisting personal records between sessions.
  • Applying the language and prefix preferences configured by the server.
  • Operating, monitoring, securing, and troubleshooting the bot.
  • Exibir rankings e histórico de partidas.
  • Persistir recordes pessoais entre sessões.
  • Aplicar as preferências de idioma e prefixo configuradas pelo servidor.
  • Operar, monitorar, proteger e diagnosticar problemas do bot.

Data is not sold or used for commercial or advertising purposes. Information necessary to fulfill a command may be sent to third-party services, which process it under their own terms and privacy policies.

Os dados não são vendidos nem utilizados para fins comerciais ou publicitários. Informações necessárias para atender a um comando podem ser enviadas a serviços de terceiros, que as processam de acordo com seus próprios termos e políticas de privacidade.

5. Retention and Deletion 5. Retenção e exclusão

Data stored in the bot's database is retained until its deletion is requested. To request deletion of your data, contact us through the support server linked below.

Os dados armazenados no banco de dados do bot são mantidos até que sua exclusão seja solicitada. Para solicitar a exclusão dos seus dados, entre em contato pelo servidor de suporte indicado abaixo.

Operational logs are retained for up to 30 days and are then automatically deleted through log rotation.

Os logs operacionais são mantidos por até 30 dias e depois são excluídos automaticamente por meio da rotação de logs.

6. Security 6. Segurança

Data is stored locally in an SQLite database and in operational log files on the bot host server. The bot does not request tokens, passwords, email addresses, or other sensitive information. Users should not submit sensitive information through bot commands.

Os dados são armazenados localmente em banco de dados SQLite e em arquivos de logs operacionais no servidor de hospedagem do bot. O bot não solicita tokens, senhas, endereços de e-mail ou outras informações sensíveis. Os usuários não devem enviar informações sensíveis por meio dos comandos do bot.

Esta política pode ser atualizada periodicamente. A data de última atualização sempre será indicada no topo da página.
